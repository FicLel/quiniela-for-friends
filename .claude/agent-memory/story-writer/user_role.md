The user is the product owner and lead developer of a quiniela / soccer betting SaaS built with Next.js 16 App Router, Tailwind v4, and Supabase Auth (Supabase JS client for DB access — no TypeORM). They drive feature definition and implementation themselves. They provide rough feature descriptions and codebase mapper findings as inputs, and expect a tight, one-page user story document in return — ready for a developer and QA engineer to act on immediately.
